# OOPS Banner Application

A modular, object-oriented Java framework designed to dynamically format, scale, and render custom text banners. Built as an academic milestone at SRMIST to master advanced Object-Oriented Programming (OOP) architectures, clean coding patterns, and professional Git branch workflows.

---

## 🚀 Key Features & Engineering Concepts

* **Object-Oriented Architecture:** Leverages abstraction, encapsulation, and polymorphism to completely isolate core formatting engines from systemic output modules.
* **Modular Code Structure:** Separates formatter processing rules from main execution modules to enforce high code reusability and scalability.
* **Dynamic Canvas Rendering:** Implements scalable calculation algorithms to modify text width, margin tracking, and structural border padding on the fly.
* **Isolated Version Control:** Developed utilizing advanced Git architecture, employing strict branch segmentation to test layouts safely prior to stable codebase merges.

## 🛠️ Tech Stack & Development Environment

* **Programming Language:** Java (JDK 17+)
* **Design Paradigm:** Object-Oriented Programming (OOP Principles)
* **Version Control System:** Git Engine & GitHub Repositories
* **Development Environments:** IntelliJ IDEA / Eclipse Integrated Platforms

## 💻 Installation & Local Execution

### Prerequisites
* Ensure you have Java Development Kit (JDK 17 or higher) configured on your local system.
* Verify your active environment paths using your system terminal: `java -version`

### Terminal Execution Steps
Run the following sequence of commands in your local machine terminal environment to clone, build, and deploy the application:

```bash
# Clone the project repository code from GitHub
git clone [https://github.com/rageshv214-bot/OOPS-Banner-App.git](https://github.com/rageshv214-bot/OOPS-Banner-App.git)

# Move into the project root directory
cd OOPS-Banner-App

# Compile the modular Java source files into binary files
javac -d bin src/*.java

# Execute the main entry file of the banner application
java -cp bin Main
